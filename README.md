📊 Enterprise System Performance Monitoring Dashboard
📌 Project Overview

This project presents an interactive system monitoring dashboard built using Microsoft Power BI to analyze cluster workload, resource utilization, and failure patterns using the Google Cluster dataset.
The dashboard transforms complex system data into clear visual insights that help monitor system performance and detect operational issues.

❗ Problem Statement

Large-scale cloud clusters execute thousands of tasks across multiple machines. Monitoring workload distribution, resource usage, and failure events becomes difficult when dealing with massive datasets. Without effective monitoring tools, it is challenging to identify inefficiencies, detect failures, and optimize system performance.

💡 Proposed Solution

An Enterprise System Performance Monitoring Dashboard was developed to visualize cluster performance metrics through interactive dashboards.
The solution enables users to:

Monitor workload distribution across clusters
Analyze CPU and memory utilization
Identify system failures and event patterns
Detect performance bottlenecks

⚙️ System Development Approach

Data Collection: Google Cluster workload dataset
Data Preprocessing: Cleaning data, handling missing values, converting time formats
Data Modeling: Creating relationships between tasks, jobs, machines, and resources
Dashboard Development: Designing interactive dashboards with KPIs and visualizations
